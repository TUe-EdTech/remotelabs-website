# Remote Labs Website

A clean, professional one-page website for Remote Labs - 24/7 Access to Physical Lab Experiments at Eindhoven University of Technology.

## Quick Start

1. Open `index.html` in any browser
2. That's it! 🚀

## Features

- ✅ Responsive design (mobile, tablet, desktop)
- ✅ Modern UI with smooth animations
- ✅ Autoplay video with clean display
- ✅ Accessibility optimized
- ✅ Cross-browser compatible

## File Structure

```
remotelabs-website/
├── index.html          # Main HTML
├── styles.css          # Full CSS
├── styles.min.css      # Minified CSS
├── script.js           # Full JavaScript
├── script.min.js       # Minified JavaScript
└── assets/             # Images (logo, team photos)
```

## Customization

- Edit text in `index.html`
- Modify colors in `styles.css`
- Update images in `assets/` folder

## Deployment

Upload all files to any web hosting service. No server requirements.

## Browser Support

✅ Chrome, Firefox, Safari, Edge  
⚠️ IE11 (basic functionality)
